## Design Guidelines
- Use PNG format with no transparency
- No rounded corners (iOS adds them automatically)
- Recommended: Create a 1024x1024 master icon and resize
- Use the Deevo Sentinel brand colors:
  - Primary: #2D6175 (Teal)
  - Accent: #F5A623 (Orange)

## Quick Generation
Use a tool like:
- https://appicon.co
- https://makeappicon.com
- Xcode's built-in icon generator

Upload your 1024x1024 PNG and it will generate all sizes.

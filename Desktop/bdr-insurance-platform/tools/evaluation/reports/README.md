# Evaluation Reports

This directory contains evaluation reports generated by the harness.

## Report Types

### 1. Evaluation Summary Reports

**Format:** `{module_name}_eval_{timestamp}.json`

**Contents:**
- Overall pass/fail rates
- Aggregate metrics
- Failed case summaries
- Governance violations
- Regression detection results

**Example:**
```json
{
  "module_name": "fnol_triage",
  "evaluation_id": "eval_fnol_triage_2026-01-20T10:00:00",
  "executed_at": "2026-01-20T10:00:00Z",
  "total_cases": 5,
  "passed_cases": 4,
  "failed_cases": 1,
  "pass_rate": 0.80,
  "governance_compliance_rate": 0.95
}
```

### 2. Metrics Snapshots

**Format:** `{module_name}_metrics_{timestamp}.json`

**Contents:**
- Decision metrics (accuracy, confidence)
- Stability metrics (volatility, drift)
- Governance metrics (compliance rates)
- Regression analysis
- Production readiness assessment

### 3. Regression Reports

**Format:** `{module_name}_regression_{timestamp}.md`

**Contents:**
- Comparison to baseline
- Detected regressions
- Severity assessment
- Recommended actions

**Example:**
```markdown
# Regression Report: fnol_triage

**Date:** 2026-01-20
**Baseline:** eval_2026-01-15

## Summary

REGRESSION DETECTED (WARNING)

## Changes

- ❌ Pass rate decreased: 95% → 80% (-15%)
- ✅ Avg confidence improved: 0.75 → 0.82 (+7%)
- ❌ Boundary violations increased: 5% → 12% (+7%)

## Recommendations

1. Investigate failed cases
2. Review boundary threshold changes
3. Do not deploy to production
```

### 4. Case-Level Reports

**Format:** `{module_name}_cases_{timestamp}.json`

**Contents:**
- Individual case results
- Detailed failure analysis
- Execution traces
- Governance violations per case

## Report Retention

- **Active reports:** Last 30 days (kept in this directory)
- **Archived reports:** Older than 30 days (moved to `reports/archive/`)
- **Baseline reports:** Marked with `_baseline` suffix (never deleted)

## Generating Reports

```python
from tools.evaluation import run_evaluation
from modules.fnol_triage.service_contract import run_fnol_triage_contract

# Run evaluation
result = run_evaluation(
    module_name="fnol_triage",
    module_executor=run_fnol_triage_contract,
)

# Save report
with open(f"reports/fnol_triage_eval_{datetime.now().isoformat()}.json", "w") as f:
    f.write(result.model_dump_json(indent=2))
```

## CI/CD Integration

Reports are automatically generated on:

1. **Pull requests:** Run evaluation, block merge if regressions detected
2. **Main branch commits:** Generate baseline reports
3. **Nightly builds:** Full evaluation suite with drift detection
4. **Pre-release:** Production readiness assessment

## Viewing Reports

### Command Line

```bash
# View latest evaluation
python tools/evaluation/view_report.py --latest fnol_triage

# Compare to baseline
python tools/evaluation/compare_reports.py \
  --current reports/fnol_triage_eval_2026-01-20.json \
  --baseline reports/fnol_triage_eval_2026-01-15_baseline.json
```

- `tools/evaluation/harness.py` - EvaluationResult
- `tools/evaluation/metrics.py` - MetricsSnapshot, RegressionMetrics

This ensures:

✅ Type safety
✅ Validation
✅ Consistent structure
✅ Easy parsing

## Governance

**Report Ownership:** Platform Team

**Review Cadence:**
- Daily: Check for critical regressions
- Weekly: Review trends and patterns
- Monthly: Baseline updates

**Escalation:**
- Critical regressions → Immediate Slack alert
- Production readiness failures → Block deployment
